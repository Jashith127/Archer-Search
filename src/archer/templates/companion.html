Browser

Make Archer the search engine in your address bar. Browsers don't let apps change this for you, so it takes three clicks.

Your browsers

{{ browser_list(state.app.browsers) }}

Chromium browsers · Helium, Chrome, Edge, Brave

  1. In Search engine → Manage search engines and site search, find Site search and click Add.
  2. Fill in the fields below.
  3. Open the ⋮ menu next to Archer and choose Make default.
{{ copy_rows([("Name", "Archer"), ("Shortcut", "ar"), ("URL with %s in place of query", search_url), ("Suggestions URL", suggest_url)]) }}

If searches don't reach Archer, use {{ fallback_search_url }} instead.

Firefox

  1. Open Archer's home page in Firefox.
  2. Right-click the address bar and choose Add “Archer”.
  3. In Settings → Search, choose Archer as the default search engine.
