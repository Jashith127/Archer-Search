Set Archer as Helium's default

● Archer is running

  1. In Helium, open Settings → Search engine → Manage search engines and site search.
  2. Next to Site search, click Add.
  3. Fill in the four fields below, then click Add as default.
NameArcher
Shortcutar

Suggestions URL with %s in place of query{{suggest_url}}

If searches don't reach Archer, swap archer.localhost for 127.0.0.1, for example {{fallback_search_url}}.

Archer must be running for searches to work. To start it when you log in, right-click the Archer tray icon and tick Start with Windows.
