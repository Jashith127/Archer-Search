Archer · brand exploration v1

The pixel grid

The brand is a field of tiny, slightly rounded squares. At rest it's a faint grid. When Archer is doing something, the pixels light up, gather into the mark and move with you. The UI stays quiet and monochrome. The grid appears only around it: the home page, loading, AI work, the favicon and the tray.

01 · The unit

One rounded square, five inks

pitch
Grid spacing. 7px on large surfaces, 4px in loaders, and whole device pixels in icons.
square
76% of pitch. The gap (24%) keeps the grid visible even where the shape is solid.
radius
35% of half the square. Rounded enough to feel modern, not so much that the pixels read as dots.
ink
One colour at five opacities. Using opacity instead of hue keeps it in line with the monochrome UI.
02 · Mark directions

Three ways to draw Archer in pixels

Each card is live. The 48, 32 and 16px versions below each one are hand-drawn bitmaps, since icon sizes need pixel-exact art.

A · Ascent Recommended

The existing chevron "A", rebuilt in pixels. Its legs break up into particles, like an arrow leaving the bow. It keeps continuity with the current mark and reads clearly down to 16px.

B · Target

A pixel bullseye that fills in from the centre: "found it." It's easy to animate as a loading state. The risk is that it reads as generic (Target, crosshair icons).

C · Caret

No symbol: the wordmark plus a blinking pixel caret, much like Cursor's own. It's the most minimal option, but it needs a separate icon (the caret block) and is the least ownable.
03 · Icons

Favicon and tray, pixel-exact

At 16px each grid cell is a whole 2×2 device-pixel block with no gap, so it's honest pixel art. Gaps appear from 32px up. The dark tile keeps the icon readable on light taskbars as well as dark ones.

06 · Rules

Keeping it modern, not retro

  • Pixels around the UI, never inside it. Result text, cards and heroes stay as they are. The grid belongs to the home page, setup, loading, AI work and icons.
  • Small pixels, large shapes. A large mark is drawn with many tiny squares rather than a few chunky ones. That separates it from 8-bit nostalgia.
  • One ink. Mono is the default. Ember (the weather accent) or Signal (rain blue) could tint a state, but never both at once.
  • Wordmark stays in DM Sans. The pixel treatment is reserved for the symbol and the field. A pixel font would date it.
  • Strict CSP fits. Everything here is canvas plus DOM in one script, so it can move into archer.js as-is.
